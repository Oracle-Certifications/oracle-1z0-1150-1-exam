## 5. Scenario-Based Demo & Practice Questions

### Question 1
Which migration method is recommended for moving an on-premises production Oracle Database to Oracle Autonomous Database with minimal downtime and continuous transactional replication during transfer?

A) Oracle Zero Downtime Migration (ZDM) with Logical Online Migration (GoldenGate + Data Pump)
B) Exporting tables to CSV files manually
C) Cold RMAN backup restore over the internet
D) Manual table recreation via SQL script

- **Correct Answer**: `A) Oracle Zero Downtime Migration (ZDM) with Logical Online Migration (GoldenGate + Data Pump)`  
- **Technical Explanation**: ZDM Logical Online Migration automates Data Pump for initial schema and data seeding, followed by Oracle GoldenGate change data capture for zero-downtime cutover.

---

### Question 2
What component must be deployed on-premises in a VMware vSphere environment to discover virtual machines and replicate their storage to OCI Cloud Migration Service?

A) OCI Cloud Migration Remote Agent Appliance
B) FastConnect Physical Cross-Connect
C) Bastion Session Plugin
D) Cloud Guard Detector Agent

- **Correct Answer**: `A) OCI Cloud Migration Remote Agent Appliance`  
- **Technical Explanation**: The OCI Cloud Migration Remote Agent is an OVA virtual appliance deployed into VMware vCenter to discover guest VMs, collect inventory, and replicate disk data to OCI.
